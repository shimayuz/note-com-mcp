# Security Policy

## Supported versions

Only the latest release receives security fixes. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the version you tested, the steps to reproduce, and what an attacker could do.

This project is maintained by one person in spare time. I aim to reply within 7 days. If the report is confirmed, I will fix it, publish a GitHub Security Advisory, and credit you unless you prefer otherwise.

## Past advisories

Published advisories are listed under the **Security** tab of this repository.
